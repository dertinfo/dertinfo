# 👋 DertInfo has moved

**This account is no longer active. DertInfo now lives in the [dertinfo-org](https://github.com/dertinfo-org) GitHub organisation.**

DertInfo is the open-source software that supports the annual **Dancing England Rapper Tournament (DERT)**. All development, documentation, issues, discussions, and project planning now happen in the organisation.

## ➡️ Go here instead

### [dertinfo-org/dertinfo-mono](https://github.com/dertinfo-org/dertinfo-mono)

The monorepo is the single source of truth for the DertInfo platform: applications, services, infrastructure, documentation, contributing guidance, and development setup. If you want to use, learn about, or contribute to DertInfo, start there.

- Raise **issues** and **pull requests** on [dertinfo-org/dertinfo-mono](https://github.com/dertinfo-org/dertinfo-mono).
- Old links to `github.com/dertinfo/dertinfo-mono` redirect automatically, but please update bookmarks, git remotes, and integrations to the new location:

  `git remote set-url origin https://github.com/dertinfo-org/dertinfo-mono.git`
